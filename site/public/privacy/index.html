MailJay

Privacy Policy

Effective date: September 20, 2026

MailJay is a macOS app by Josh Johnson / Secondfret Software. This policy explains how MailJay accesses, uses, stores, shares, protects, and deletes Google user data and other information related to the app.

Summary

MailJay does not operate a Secondfret backend that stores your email. Google OAuth tokens and your Jev API key stay on your Mac. Message content is sent only to Google (to read and modify your mailbox) and to TypeSafe’s Jev API (to classify mail), using credentials you control. Secondfret does not sell Google user data and does not use it for advertising.

Information MailJay accesses

  • Gmail account data after you sign in with Google OAuth. MailJay requests the https://www.googleapis.com/auth/gmail.modify scope so it can read inbox messages and, only when you approve an action, archive mail, move mail to Gmail Trash, or apply Jev/… labels.
  • Message metadata and content needed for triage (for example sender, subject, snippet or body text) so Jev can suggest a category.
  • Your TypeSafe Jev API key, which you paste into the app.
  • App preferences stored locally (for example message fetch limits and auto-fetch settings).

How Google user data is used

MailJay uses Google user data only to provide user-facing inbox triage features in the app:

  • Fetch and display recent Gmail messages for review.
  • Send message text needed for classification to TypeSafe’s Jev API using your API key.
  • Apply archive, trash, or label changes that you explicitly approve in the app.

MailJay does not use Google user data for advertising, credit decisions, or unrelated analytics. Use is limited to the practices described in this policy.

How Google user data is shared, transferred, or disclosed

MailJay shares or transfers Google user data only as follows:

  • Google / Gmail: MailJay sends API requests to Google to authenticate you and to read or modify your mailbox under the scopes you grant. Google processes that data under Google’s own policies for your Google account.
  • TypeSafe (Jev): To categorize mail, MailJay sends message text or snippets and your category descriptions to TypeSafe’s Jev API using your TypeSafe API key. TypeSafe processes that content to return a category suggestion under TypeSafe’s policies. Secondfret does not operate or control TypeSafe’s servers.
  • Secondfret Software: MailJay does not upload your Gmail messages, OAuth tokens, or Jev API key to secondfret.net or any Secondfret-operated backend. Josh Johnson / Secondfret Software does not receive copies of your mailbox contents through the app.
  • No sale or ads: We do not sell Google user data. We do not transfer Google user data to advertising platforms, data brokers, or information resellers. We do not use Google user data to serve ads.
  • Legal / safety exceptions: We may disclose information if required by applicable law, regulation, legal process, or governmental request, or to protect the security, rights, or safety of users or the public, when we believe disclosure is reasonably necessary. Because MailJay does not host your Gmail data on Secondfret servers, Secondfret typically has no mailbox content to disclose.
  • Business transfer: If Secondfret Software is involved in a merger, acquisition, or sale of assets, we would obtain your explicit prior consent before transferring Google user data as part of that transaction, consistent with Google’s Limited Use requirements.

App update checks contact MailJay’s Cloudflare-hosted release site (Sparkle). Those requests do not include your Gmail message content or OAuth tokens.

Data protection

MailJay protects sensitive data with the following mechanisms:

  • Local storage of secrets: Google OAuth access and refresh tokens and your Jev API key are stored in the macOS Keychain on your Mac.
  • Local-only mailbox cache: Triage results, categories, and preferences are stored in local application support files on your Mac. They are not synced to Secondfret servers.
  • Encrypted transport: Network requests to Google and TypeSafe use HTTPS.
  • User-approved mailbox changes: Archive, trash, and label modifications are not applied until you confirm them in the app.
  • No Secondfret cloud copy: Because Secondfret does not host your Gmail data, there is no Secondfret server-side copy of your mailbox for attackers to breach through our infrastructure.
  • Device security: Protection also depends on your Mac’s lock screen, user account, and macOS security settings. You should keep your device and OS up to date.

Retention and deletion of Google user data

Retention while you use MailJay:

  • OAuth tokens remain in Keychain until you disconnect the Google account in MailJay, clear related Keychain items, or remove the app’s data.
  • Local triage caches and category settings remain on your Mac while the account is connected so the app can show prior results and preferences.
  • Message content sent to TypeSafe is processed to return a classification; MailJay does not keep a separate Secondfret cloud archive of that content. Retention by TypeSafe or Google is governed by their policies.

How to delete data associated with MailJay:

  • Disconnect in the app: Removing or disconnecting a Gmail account in MailJay deletes that account’s OAuth token from MailJay’s Keychain storage and clears that account’s local triage cache and category files on your Mac.
  • Revoke access in Google: You can also revoke MailJay’s access at any time in your Google Account’s third-party app settings. After revocation, MailJay can no longer call the Gmail API with those credentials until you connect again.
  • Uninstall / remove local files: Deleting the MailJay app and its Application Support / preferences data removes remaining local caches and preferences from your Mac. You can also delete Keychain items associated with MailJay if any remain.
  • Gmail mailbox content: Archive or Trash actions you approve change your Gmail mailbox itself. Those changes (and emptying Trash) are controlled in Gmail / Google Account settings, not by a Secondfret server retention clock.

Because Secondfret does not store your Google user data on our servers, there is no separate Secondfret cloud retention period for mailbox contents. Once local app data is cleared and Google access is revoked, Secondfret retains no Google user mailbox data from MailJay.

Where data is stored

  • Mac Keychain: Google OAuth tokens and your Jev API key.
  • Local app storage on your Mac: triage categories, preferences, and a local cache of loaded triage results.
  • MailJay does not upload your mailbox, tokens, or API key to secondfret.net or any Secondfret server.

Third-party services

  • Google / Gmail: authentication and Gmail API access. See Google’s Privacy Policy.
  • TypeSafe Jev: classification of message text using your API key. See TypeSafe’s terms and privacy documentation for how they handle API requests.
  • Sparkle / Cloudflare: optional app update checks and download of signed update packages from MailJay’s Cloudflare-hosted release site. Update checks do not include your Gmail content.

What MailJay does not do

  • No ads, no analytics SDKs, and no sale of personal information.
  • No permanent delete from Gmail via the app’s delete action — messages are moved to Gmail Trash.
  • No archive, trash, or label changes until you explicitly approve them in the app.
  • No transfer of Google user data for advertising or data-broker purposes.

Children

MailJay is not directed at children under 13, and we do not knowingly collect personal information from children.

Changes
