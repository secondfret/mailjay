MailJay

Privacy Policy

Effective date: September 19, 2026

MailJay is a macOS app by Josh Johnson / Secondfret Software. This policy explains what data MailJay accesses, where it is stored, and who it is sent to.

Summary

MailJay does not operate a Secondfret backend that stores your email. Gmail access tokens and your Jev API key stay on your Mac. Message content is sent only to Google (to read and modify your mailbox) and to TypeSafe’s Jev API (to classify mail), using credentials you control.

Information MailJay accesses

  • Gmail account data after you sign in with Google OAuth. MailJay requests the gmail.modify scope so it can read inbox messages and, only when you approve an action, archive mail, move mail to Trash, or apply Jev/… labels.
  • Message metadata and content needed for triage (for example sender, subject, snippet/body text) so Jev can suggest a category.
  • Your TypeSafe Jev API key, which you paste into the app.

Where data is stored

  • Mac Keychain: Google OAuth tokens and your Jev API key.
  • Local app storage on your Mac: triage categories, preferences, and a local cache of loaded triage results.
  • MailJay does not upload your mailbox, tokens, or API key to secondfret.net or any Secondfret server.

Third-party services

  • Google / Gmail: authentication and Gmail API access. Google’s own policies apply to your Google account.
  • TypeSafe Jev: MailJay sends message text/snippets and your category criteria to TypeSafe’s API using your API key so Jev can return a category suggestion. TypeSafe’s policies apply to that processing.
  • Sparkle / Cloudflare: the app may check for updates and download signed update packages from MailJay’s Cloudflare-hosted release site. Update checks do not include your Gmail content.

What MailJay does not do

  • No ads, no analytics SDKs, and no sale of personal information.
  • No permanent delete from Gmail via the app’s delete action — messages are moved to Gmail Trash.
  • No archive, trash, or label changes until you explicitly approve them in the app.

Children

MailJay is not directed at children under 13, and we do not knowingly collect personal information from children.

Changes

This policy may be updated from time to time. The effective date at the top of this page will change when it does. Continued use of MailJay after an update means you accept the revised policy.
